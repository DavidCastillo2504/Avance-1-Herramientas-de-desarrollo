SABOR WEB APP - DEMO FRONTEND
==============================

Tecnologías:
- HTML5
- CSS3
- JavaScript puro
- localStorage del navegador para simular persistencia

Funciones incluidas:
1. Menú digital con categorías, precios y disponibilidad.
2. Pedido online con carrito, cantidades y total automático.
3. Reservas con fecha, hora y número de comensales.
4. Panel administrativo para:
   - ver pedidos
   - cambiar estado de pedidos
   - ver reservas
   - cambiar disponibilidad de platos
   - revisar clientes frecuentes
5. Diseño responsive.

CÓMO EJECUTAR
-------------
Opción rápida:
- Abre index.html con doble clic.

Opción recomendada (VS Code):
- Instala la extensión Live Server.
- Clic derecho en index.html > Open with Live Server.

No requiere Node.js, npm, base de datos ni servidor backend.
Los datos de prueba se guardan en localStorage del navegador.
